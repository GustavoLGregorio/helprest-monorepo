## Summary  
The diagram models the interactions of various stakeholders—regular users, establishment administrators, system administrators, and the system itself—with a comprehensive set of functionalities for authentication, user profile management, discovery, visits, social sharing, establishment management, menu handling, franchise hierarchy, analytics, and administrative oversight. It also captures internal processes such as recommendation scoring, caching, and notification delivery, as well as relationships between use cases through includes, extends, and actor inheritance.

## Actors  
- **Usuário**: Regular app user who interacts with the system for discovery, visits, and social features.  
- **Establishment Admin**: Owner or manager of a single establishment, responsible for managing the establishment’s profile, menu, and local analytics.  
- **Admin**: System administrator with authority over system-wide flags and user moderation.  
- **SuperAdmin**: Highest-level administrator who can view global dashboards and audit logs, and manage all admin-level functions.  
- **Sistema**: Internal system processes that execute background tasks and algorithms.

## Use Cases  
- **Registrar-se via e-mail/senha**: Create a new account using email and password.  
- **Login via e-mail/senha**: Authenticate using stored credentials.  
- **Login via Google OAuth2**: Authenticate using Google OAuth.  
- **Renovar Token**: Refresh authentication tokens.  
- **Visualizar Perfil**: View personal profile details.  
- **Editar Perfil**: Update personal profile information.  
- **Selecionar Flags de Restrição Alimentar**: Choose dietary restrictions/preferences.  
- **Visualizar Mapa com Estabelecimentos**: See a map of nearby establishments.  
- **Buscar Estabelecimentos por Texto**: Search establishments by keyword.  
- **Receber Recomendações Personalizadas**: Get algorithmically generated recommendations.  
- **Listar Estabelecimentos Próximos**: List establishments within a given radius.  
- **Visualizar Detalhes do Estabelecimento**: View details of a selected establishment.  
- **Filtrar Cardápio por Flags do Usuário**: Show menu items matching user dietary flags.  
- **Registrar Visita com Avaliação**: Log a visit and optionally leave a review.  
- **Ver Histórico de Visitas**: Review past visits.  
- **Ver Avaliações do Estabelecimento**: See all reviews for an establishment.  
- **Favoritar Estabelecimento**: Mark an establishment as a favorite.  
- **Criar Listas Personalizadas**: Build custom lists of establishments.  
- **Compartilhar Listas**: Share a list with others.  
- **Publicar Fotos de Visita**: Upload photos from a visit.  
- **Seguir Outros Usuários**: Follow other app users.  
- **Ver Feed Social**: Browse a social feed of friends’ activities.  
- **Cadastrar Estabelecimento**: Register a new establishment.  
- **Editar Perfil do Estabelecimento**: Update establishment details.  
- **Gerenciar Flags Atendidas**: Set which dietary flags the establishment can accommodate.  
- **Visualizar Visitas e Avaliações Recebidas**: Review visits and reviews received.  
- **Adicionar Alimento ao Catálogo**: Add a new food item to the catalog.  
- **Usar Alimento do Catálogo Base**: Reuse an existing catalog item.  
- **Criar Cardápio com Categorias**: Build a menu with categories.  
- **Ativar/Desativar Cardápio ou Item**: Toggle availability of menus/items.  
- **Informar Dados Nutricionais e Alérgenos**: Supply nutrition and allergen info.  
- **Propagar Cardápio para Filiais**: Distribute a menu to franchise locations.  
- **Criar Filial Vinculada à Matriz**: Add a branch linked to a parent.  
- **Editar Filial**: Modify branch details.  
- **Herdar Flags da Matriz**: Inherit dietary flags from the parent.  
- **Override de Flags por Filial**: Override inherited flags at the branch level.  
- **Visualizar Histórico de Alterações de Filiais**: See branch change history.  
- **Aplicar Alterações em Lote nas Filiais**: Bulk apply changes to branches.  
- **Ver Métricas de Exposição**: View exposure statistics for an establishment.  
- **Ver Análise de Flags por Visibilidade**: Analyze visibility of dietary flags.  
- **Ver Métricas de Visitas e Avaliações**: Track visit and review metrics.  
- **Ver Segmentação de Visitantes por Flags**: Segment visitors by dietary preferences.  
- **Ver Funil de Conversão**: Inspect the conversion funnel.  
- **Ver Dashboard Global**: Access system-wide dashboard.  
- **CRUD de Flags**: Create, read, update, delete dietary flags.  
- **Madrar Avaliações**: Moderate user reviews.  
- **Gerenciar Usuários**: Manage user accounts.  
- **Ver Logs de Auditoria**: Inspect audit logs.  
- **Agrupar Flags por Categoria**: Group flags into categories.  
- **Desativar Flag com Soft Delete**: Soft-delete a flag.  
- **Calcular Score de Recomendação**: Compute recommendation scores.  
- **Recalcular Rating do Estabelecimento**: Update overall rating.  
- **Aplicar Rate Limiting**: Enforce request limits.  
- **Gerenciar Cache**: Handle caching mechanisms.  
- **Contabilizar Impressões e Cliques**: Track impressions and clicks.  
- **Validar Compatibilidade Flag x Cardápio**: Ensure menu matches dietary flags.  
- **Enviar Push Notifications**: Dispatch push notifications.

## Relationships between Actors and Use Cases  
- **Usuário** → all user-facing use cases (UC1–UC42).  
- **Establishment Admin** → all establishment management and analytics use cases (UC16–UC47).  
- **Admin** → administrative (UC49–UC54).  
- **SuperAdmin** → global dashboard, admin functions, and audit logs (UC48–UC54).  
- **Sistema** → background processing use cases (UC18–UC21, UC55–UC57).
